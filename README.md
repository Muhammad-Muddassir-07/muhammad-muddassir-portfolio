# Muhammad Muddassir Farhan — Portfolio

A professional personal portfolio website built as part of the MTech Solutions Frontend Development Internship Batch 01 — Task 01.

## About the Project

This portfolio presents my background, technical skills, selected projects, services, and contact information in a responsive modern interface.

The website was developed using React and Vite with a component-based structure and responsive CSS.

## Features

- Responsive design for desktop, tablet and mobile
- Mobile hamburger navigation
- Hero section
- About section
- Technical skills section
- Selected projects section
- Services section
- Contact form with frontend validation
- Formspree contact form integration
- Social/contact links
- Responsive footer
- SEO meta information
- Custom favicon

## Technologies

- React
- JavaScript

- CSS3
- Vite
- Formspree
